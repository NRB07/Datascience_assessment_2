 FIFA World Cup 2026 – Data Science Analysis

## HIT140 Assessment 2 – Group 11

This repository contains the Python-based data analysis completed by **Group 11** for HIT140 Assessment 2.

The project analyses FIFA World Cup 2026 player performance across different areas of football using data preparation, descriptive statistics, confidence intervals, sampling techniques, visualisation, and hypothesis testing.

---

## Project Objective

The main objective of this project is to apply data science and statistical analysis techniques to football performance data.

Our group investigated four different areas of player performance:

1. **Shooting Analysis**
2. **Defending Analysis**
3. **Goalkeeper Analysis**
4. **Fouls Committed Analysis**

Each task focuses on a different analytic question while following a similar data science workflow.

---
## Group Members and Task Distribution

The FIFA World Cup 2026 analysis was divided among four group members, with each member responsible for a different area of player performance.

| Group Member | Analysis Task | Main Focus |
|---|---|---|
